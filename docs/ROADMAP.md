# Roadmap

## M1 - Presence / Follow
- Steam launch detection
- Valheim process launch
- BepInEx plugin bootstrap
- WebSocket protocol
- Player state heartbeat
- chat/status/follow/stop commands
- local steering and stuck detection

## M2 - Worker
- object perception
- gather wood/stone
- chest indexing and deposits
- inventory capacity handling
- repair/eat/rest routines
- farming and smelters

## M3 - Combat Companion
- threat scoring
- target selection
- melee/ranged behavior
- block/dodge/flee
- party-follow spacing

## M4 - Independent Tasks
- remembered map locations
- portal routing
- mining runs
- corpse recovery assistance
- task queue and resumable goals

## M5 - Personality / Voice
- Valheim chat natural-language commands
- Discord voice input/output
- speech-to-text / text-to-speech
- persistent preferences and location memory

## M6 - Advanced
- sailing
- dungeon navigation
- building
- Ashlands/Deep North specialized behaviors
